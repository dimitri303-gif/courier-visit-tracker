# Telegram Naming Convention

Усі нові файли, які створюються для інтеграції Telegram-бота (особливо в папці `backend_TG`), повинні містити суфікс `_TG` у назві для легкої візуальної ідентифікації.

**Приклади:**
- `TelegramBot_TG.gs`
- `ServerVisitDetector_TG.gs`
- `Router_TG.gs`
- `Config_TG.gs`

**Неправильно:**
- `TelegramBot.gs`
- `Router.gs`

Завжди дотримуйтесь цього правила при створенні або перейменуванні файлів, що стосуються логіки Telegram.
